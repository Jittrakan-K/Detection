# ระบบนับจำนวนสิ่งของจากกล้องแบบ Real-Time (AI Object Counter)

โปรแกรมตรวจจับ ติดตาม และนับจำนวนสิ่งของจากกล้อง (Webcam / USB Camera / Video File) แบบเรียลไทม์ โดยใช้ **YOLOv8 + ByteTrack + PyTorch CUDA GPU** (รองรับ NVIDIA GeForce RTX 3050 Ti) พร้อมหน้าจอ HUD ภาษาไทย

---

## จุดเด่นของระบบ (Key Features)

- ⚡ **GPU Acceleration:** ประมวลผลลื่นไหลด้วย GPU (RTX 3050 Ti) ทำเฟรมเรตได้สูง 30-60+ FPS
- 🇹🇭 **Thai HUD & Display:** แสดงผลภาษาไทยบนหน้าจอคมชัด (ชื่อวัตถุ, สถิติการนับ, แผงควบคุม)
- 🎯 **2 โหมดการนับอเนกประสงค์:**
  1. **นับในภาพสด (In-Frame Live Count):** นับจำนวนสิ่งของที่มีอยู่ในเฟรม ณ ขณะนั้นทันที (เหมาะสำหรับนับสต๊อก/ของบนโต๊ะ)
  2. **นับข้ามเส้นสะสม (Line-Crossing Count):** นับเมื่อวัตถุเคลื่อนที่ตัดผ่านเส้นเสมือน มีระบบตรวจจับทิศทาง เข้า (IN) / ออก (OUT) และป้องกันการนับซ้ำด้วย Tracking ID (เหมาะสำหรับสายพานลำเลียงหรือทางเดิน)
- 🖥️ **รองรับทั้ง GUI และ Command Line:** มีหน้าต่างตั้งค่าแบบคลิกง่าย หรือสั่งผ่านคำสั่งพร้อมคีย์ลัดบนคีย์บอร์ด

---

### 1. ใช้งานผ่านเว็บเบราว์เซอร์ (HTML5 Web Dashboard) - สะดวกและสวยงามที่สุด 🌐
คุณสามารถเปิดใช้งานได้ 2 วิธีง่ายๆ:

- **วิธี ก (รันเซิร์ฟเวอร์เปิดเบราว์เซอร์อัตโนมัติ):**
  ```bash
  python index.py
  ```
  *(ระบบจะรัน Server และเปิดหน้าเว็บ `http://localhost:5000` ให้ทันที)*

- **วิธี ข (ดับเบิลคลิกไฟล์ตรง):**
  - ดับเบิลคลิกเปิดไฟล์ `index.html` ในโฟลเดอร์นี้ผ่านเบราว์เซอร์ได้ทันที!
  - รองรับทั้งการรับสตรีมจาก Python GPU หรือเปิดกล้องเว็บแคมตรงผ่านเบราว์เซอร์ (HTML5 Direct Webcam)

- รับชมสตรีมวิดีโอแบบสดๆ พร้อมกรอบ Bounding Box และสถิติตัวเลข
- สลับโหมด *นับในภาพ* หรือ *นับข้ามเส้น* ได้ทันทีผ่านปุ่มบนเว็บ
- เลือกสิ่งของที่ต้องการนับผ่าน Quick Chips (ขวดน้ำ, คน, แก้ว, มือถือ, หนังสือ, รถยนต์ ฯลฯ)
- มีสไลเดอร์ปรับ Confidence และตำแหน่งเส้นตรวจจับ
- มีปุ่มรีเซ็ต และปุ่มถ่ายภาพหน้าจอ (Snapshot) ดาวน์โหลดได้ทันที

---

### 2. ใช้งานผ่านหน้าจอควบคุมเดสก์ท็อป (GUI Launcher)
เปิดโฟลเดอร์นี้ใน Terminal แล้วรันคำสั่ง:
```bash
python gui_app.py
```
- สามารถคลิกเลือกกล้อง (Webcam 0 หรือ 1 หรือเลือกไฟล์วิดีโอ)
- เลือกสิ่งของยอดนิยมจากรายการ (เช่น ขวดน้ำ, แก้ว, คน, มือถือ ฯลฯ)
- ปรับค่าความแม่นยำ (Confidence) แล้วกดปุ่ม **เริ่มเปิดกล้องตรวจจับ (Start)** ได้ทันที

---

### 3. ใช้งานผ่านคำสั่งด่วน (Command Line)
รันเปิดกล้องเริ่มต้นทันที:
```bash
python main.py
```

#### ตัวอย่างคำสั่งเฉพาะทาง:
- **นับเฉพาะขวดน้ำ (bottle):**
  ```bash
  python main.py --class bottle
  ```
- **นับขวดน้ำและแก้วน้ำพร้อมกัน:**
  ```bash
  python main.py --class bottle cup
  ```
- **เปิดโหมดนับข้ามเส้น (Line-Crossing):**
  ```bash
  python main.py --mode line_crossing
  ```
- **ใช้วิดีโอจากไฟล์แทนกล้อง:**
  ```bash
  python main.py --source "path/to/video.mp4"
  ```
- **ใช้กล้อง USB ภายนอก (Camera Index 1):**
  ```bash
  python main.py --source 1
  ```

## ปุ่มลัดบนคีย์บอร์ดขณะเปิดกล้อง (Interactive Keyboard Shortcuts)

| ปุ่ม | การทำงาน |
| :---: | :--- |
| **`C`** | **สลับวัตถุเป้าหมาย (Cycle Classes):** สลับระหว่าง ทั้งหมด -> ขวดน้ำ -> แก้วน้ำ -> คน -> มือถือ -> หนังสือ -> เก้าอี้ ฯลฯ |
| **`M`** | **สลับโหมดการนับ:** สลับระหว่าง *นับในภาพสด* กับ *นับข้ามเส้นสะสม* |
| **`R`** | **รีเซ็ตตัวนับ:** ล้างค่าตัวเลขการนับทั้งหมดกลับเป็น 0 |
| **`S`** | **แคปเจอร์ภาพ:** บันทึกภาพปัจจุบันพร้อมตัวเลขและกรอบตรวจจับลงในโฟลเดอร์ `screenshots/` |
| **`+` / `-`** | **ปรับค่า Confidence:** เพิ่มหรือลดความไวในการตรวจจับวัตถุ |
| **`W` / `X`** | **เลื่อนตำแหน่งเส้นนับ:** เลื่อนเส้นตรวจจับ ขึ้น (`W`) หรือ ลง (`X`) |
| **`Q` / `ESC`** | **ออกจากโปรแกรม** |

## หากต้องการนับสิ่งของเฉพาะทางที่ไม่มีใน COCO (Custom Objects)
โมเดลเริ่มต้นรองรับวัตถุทั่วไป 80 ชนิด หากคุณต้องการนับชิ้นงานเฉพาะทาง (เช่น ซองสินค้าเฉพาะ, ยา, ชิ้นงานโรงงาน):
1. ถ่ายรูปชิ้นงาน 50-100 รูป
2. ติดป้ายกำกับ (Labeling) บน [Roboflow](https://roboflow.com)
3. Train โมเดล YOLOv8 ด้วยคำสั่งสั้นๆ:
   ```bash
   yolo detect train data=your_dataset.yaml model=yolov8n.pt epochs=50 imgsz=640
   ```
4. นำไฟล์น้ำหนักโมเดลผลลัพธ์ `best.pt` มาวาง แล้วสั่งรัน:
   ```bash
   python main.py --model best.pt
   ```
