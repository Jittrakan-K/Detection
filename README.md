## 🌟 2 รูปแบบการทำงานหลัก (Dual Inspection Engines)

### 01 : ตรวจนับตามขนาด & รูปทรง (ZERO-CODE / Geometric Engine)
* **จุดเด่น:** เร็วระดับ 60 FPS แท้ ไม่ต้องโหลดไฟล์โมเดล ไม่ต้องเขียนโค้ด ไม่ต้องต่อเน็ต
* **เหมาะสำหรับ:** วัตถุชนิดเดียวกันที่มีรูปร่างแน่นอน เช่น น็อตหกเหลี่ยม, ฝาขวดน้ำ, โอริงยาง, เม็ดยา, ชิ้นส่วนปั๊มโลหะ
* **ฟังก์ชันปรับแต่งเฉพาะโหมด:**
  1. **ปุ่มดูภาพ Mask ขาว-ดำ (`ดูภาพ MASK ขาว-ดำ`):** สลับดูภาพไบนารีที่กล้องเห็น เพื่อเทียบค่าคอนทราสต์กับพื้นหลังสายพานได้ทันที
  2. **เกณฑ์ตัดแสง (Contrast Threshold):** สไลเดอร์ 20 - 240 สำหรับแยกวัตถุออกจากพื้นหลัง
  3. **ขนาดพื้นที่ต่ำสุด (Min Object Area):** กรองฝุ่น ผง สนิม หรือจุดรบกวนขนาดเล็กที่ไม่ใช่น็อต
  4. **ขนาดพื้นที่สูงสุด (Max Object Area):** กรองเงามืดขนาดใหญ่ แสงสะท้อน หรือขอบสายพาน
  5. **ตัวกรองรูปทรง (Shape Aspect Ratio):** เลือกนับเฉพาะทรงกลม/หกเหลี่ยมสมมาตร หรือชิ้นงานทรงยาว (เช่น สลักเกลียว)
  6. **ระบุชื่อชิ้นงาน (Custom Object Label):** พิมพ์ตั้งชื่อชิ้นงานเพื่อบันทึกลงรายงานและไฟล์ Excel ได้ทันที

---

### 02 : จำแนกหลายประเภทด้วย AI (YOLO MULTI-CLASS / Deep Learning)
* **จุดเด่น:** จำแนกและนับวัตถุหลายชนิดพร้อมกันบนหน้าจอเดียวได้ แยกแยะชิ้นงานที่มีขนาดใกล้เคียงกัน หรือตรวจสอบชิ้นงานเสีย (NG) ได้
* **เหมาะสำหรับ:** สายการผลิตที่มีชิ้นส่วนผสมกัน หรือมีชิ้นงานหลุด QC (เช่น น็อต M8 vs น็อต M6 vs สลัก Bolt vs แหวนรอง Washer vs งานชำรุด NG)
* **ฟังก์ชันปรับแต่งเฉพาะโหมด:**
  1. **ช่องโหลดโมเดล ONNX (.onnx File Selector / Dropzone):** โหลดไฟล์ `best.onnx` ที่เทรนจาก Google Colab หรือโฟลเดอร์ `models/best.onnx` มารันบนเบราว์เซอร์ผ่าน WebAssembly/WebGL
  2. **ระบบจำลองหลายชนิดชิ้นงาน (Built-in Multi-Class Simulation):** มีระบบจำลองพร้อมใช้งานทันที 5 คลาส (Nut M8, Nut M6, Bolt, Washer, NG Defect) แม้ไม่ได้ต่อโมเดล
  3. **ตัวกรองชนิดที่ต้องการนับ (Class Filter Checklist):** ติ๊กเลือกเฉพาะชิ้นงานที่ต้องการนับ เช่น ติ๊กนับเฉพาะ Nut M8 และ Bolt แต่ไม่นับ Washer
  4. **การ์ดสรุปยอดนับแยกตามชนิด (Multi-Class Tally Cards):** แสดงตัวเลขยอดเข้า/ออกแยกตามชนิดแบบเรียลไทม์
  5. **เกณฑ์ความมั่นใจ (Confidence Threshold):** ปรับเกณฑ์ความมั่นใจ 20% - 95%

## 📦 วิธีนำไปใช้นับวัตถุอื่นๆ ที่ไม่ใช่น็อต (HOW TO COUNT ANY OBJECT)

ระบบนี้ไม่ได้จำกัดเฉพาะน็อต แต่ถูกสร้างเป็น **Industrial Counting Framework** รองรับวัตถุทุกประเภท:

### 1. นับด้วยโหมด 01 (ZERO-CODE / ขนาด & รูปทรง) — ไม่ต้องใช้ AI
* **ชิ้นงานที่รองรับ:** ฝาขวดน้ำ, กล่องพัสดุ, โอริงยาง, เม็ดยา, ชิ้นส่วนพลาสติก, ขวดแก้ว, ผลไม้
* **วิธีทำ:**
  1. สลับแหล่งภาพเป็น **Live Webcam** หรือนำเข้าไฟล์วิดีโอ `.mp4`
  2. เปิดสวิตช์ **`ดูภาพ MASK ขาว-ดำ`**
  3. ปรับระดับ Contrast Threshold ให้วัตถุกลายเป็นสีขาว และพื้นหลังสายพานเป็นสีดำสนิท
  4. ปรับ Min/Max Area ให้ครอบคลุมขนาดของวัตถุจริง
  5. พิมพ์ชื่อวัตถุในช่อง **`ชื่อวัตถุที่ต้องการนับ`** เช่น "ฝาขวดน้ำดื่ม" หรือ "กล่องพัสดุ"

### 2. นับด้วยโหมด 02 (YOLO MULTI-CLASS) — AI ความแม่นยำสูง
* **ชิ้นงานที่รองรับ:** วัตถุคละแบบหลายประเภท, มีการบดบังบางส่วน, แสงสะท้อนซับซ้อน หรือแยกชิ้นงานดี/เสีย (OK/NG)
* **วิธีทำ:**
  1. ถ่ายภาพชิ้นงานจริงบนสายพาน 50-100 รูป
  2. อัปโหลดไปติด Label Bounding Box บน [Roboflow](https://roboflow.com)
  3. เทรนด้วยไฟล์สมุดงาน [`Train_YOLOv11_Colab.ipynb`](file:///d:/etc/WORK/PROJECT%20DOCUMENT/COUNT%20OBJECT/Train_YOLOv11_Colab.ipynb) บน Google Colab ฟรี
  4. ดาวน์โหลด `best.onnx` แล้วลากมาวางในช่อง Dropzone บนหน้าเว็บ [index.html](file:///d:/etc/WORK/PROJECT%20DOCUMENT/COUNT%20OBJECT/index.html)

### 3. ทดลองด้วยวัตถุจำลอง 5 รูปแบบในตัวจำลอง (SIMULATOR PRESETS)
คุณสามารถทดสอบพฤติกรรมการตรวจนับของวัตถุแต่ละชนิดได้ทันทีผ่านเมนูดรอปดาวน์ **`วัตถุจำลอง (SIMULATOR PRESET)`**:

* 📦 **กล่องพัสดุ & หีบห่อ (CARTON BOXES)**
* ⭕ **โอริง & แหวนยาง (RUBBER O-RINGS)**
